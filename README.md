# Half&Half

물체의 숨겨진 질량을 좌우 50:50에 가깝게 나누는 모바일 게임입니다. 보이는 모델과 질량 판정을 분리하고, 절단 결과로 다음 시도를 개선하는 흐름을 만듭니다.

- iOS: https://apps.apple.com/app/id6821765037
- 기술: Unity, C#, URP, Unity Localization, Apple Game Center, Google AdMob·UMP
- 공개 범위: 게임 규칙·저장·랭킹·광고·UI 소스와 관련 테스트 코드

## 직접 판단한 일과 AI 활용

게임 규칙·콘텐츠 범위·작업 우선순위를 정하고 결과를 검토했습니다. Codex와 Unity 도구를 활용해 구현과 검증을 진행했습니다. 코드 전체를 혼자 직접 작성했거나 모든 기술을 독립적으로 숙련했다고 주장하지 않습니다.

사과 한 개의 플레이 루프부터 저장·랭킹·콘텐츠·다국어·출시로 작업을 나누었습니다. 진행 중 외형 보강과 기능 연결의 우선순위를 바꾸고, 29종에서 24종으로 범위를 조정하면서 기존 ID와 기록을 보존했습니다. 검증은 변경 기능과 실제 사용에 필요한 범위를 우선했습니다.

## 코드 읽기

`UnityProject/Assets/HalfAndHalf/` 아래:

- `Core/`: 질량 분할·정확도·시도 규칙
- `Gameplay/`, `Presentation/`: 게임 실행과 절단 표현
- `Services/`: 로컬 기록·온라인 제출·광고 연동
- `UI/`: HUD·컬렉션·사용자 흐름
- `Tests/`: 관련 EditMode·PlayMode 테스트

`UnityProject/Assets/Plugins/iOS/`에는 프로젝트 전용 네이티브 연동 코드 일부를 포함합니다.

## 공개용 사본의 제한

코드 검토용 소스 스냅샷이며 완전한 Unity 프로젝트 배포본이 아닙니다. 이미지·모델·텍스처·음원·폰트·씬·프리팹·직렬화 자산, 빌드·기기 기록·사용자 데이터, 서명·광고 운영 설정, 내부 보고서와 기존 Git 이력은 포함하지 않습니다.

Package manifest와 Unity 버전 파일은 개발 환경 참고용입니다. 별도 SDK 패키지·플러그인과 게임 리소스를 제외했으므로 이 저장소만으로 실행·빌드·테스트할 수 없습니다. 코드 내 광고 ID는 Google 공식 테스트 ID이며 실제 광고 운영 설정은 포함하지 않습니다.

코드와 콘텐츠의 재배포·상업적 이용 허가는 별도로 부여하지 않습니다.
